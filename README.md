# Console Banking App

A simple Java console-based banking application built to demonstrate Object-Oriented Programming concepts.

## Features
- Create Savings and Current accounts
- Deposit money
- Withdraw money
- View account balance

## OOP Concepts Used

### Encapsulation
Private variables are accessed through public methods.

### Inheritance
SavingsAccount and CurrentAccount extend the Account class.

### Polymorphism
Different account types use the same Account reference and override the withdraw() method.

### Abstraction
Account is an abstract class that defines common account behavior.
